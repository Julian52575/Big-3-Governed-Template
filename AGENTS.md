# Agent instructions

Read [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md) before
changing anything; they are the source of truth. The hard rules:

- **Conventional Commits** for every commit and PR title:
  `<type>[(scope)][!]: description`, lower-case subject, no trailing period.
- **Signed, signed-off commits**: `git commit -s` with signing configured;
  the `commit-msg` hook rejects anything else.
- **Every PR closes an issue** (`Closes #NNN` in the body). Branch from `main`;
  never push to `main`.
- **Workflows** (`.github/`):
  - pin every action to a full commit SHA with a `# vX.Y.Z` comment that
    matches it (`pin-github-action` does this);
  - least-privilege `permissions:` at workflow level, widened per job only
    where needed;
  - `timeout-minutes` on every job, `step-security/harden-runner` as each
    job's first step, `persist-credentials: false` on every checkout;
  - never expand `${{ … }}` inside `run:` — pass it through `env:`;
  - make a new job mandatory by adding it to `ci-required.needs` in
    `ci.yml`, never by editing `.github/rulesets/main.json`.
  - Run `just lint-workflows` (actionlint, zizmor, schema) before committing.
- **Tooling** comes from the Nix dev shell (`nix develop`). Add a tool to
  `flake.nix`, or to `nix/tools.nix` when nixpkgs lags the version CI uses.
- **Secrets** never go in git. New variables go in `.env.example` with a safe
  placeholder; `change-me-*` values are generated by the shell.
- **Comments** stay short and explain why, not what.
- Record incidents and their fixes in `docs/Troubleshoot.md`.
- AI-assisted commits carry a `Co-Authored-By:` trailer naming the assistant.
